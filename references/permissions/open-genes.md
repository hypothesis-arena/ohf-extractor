# Open Genes data: permission from Open Longevity

Date: 2026-10-21.

Open Genes (https://open-genes.com) is a project of Open Longevity (https://openlongevity.org).
Open Longevity permits reuse of the Open Genes database content (web pages, API responses,
TSV exports and the database dump) under the Creative Commons Attribution 4.0 International
licence (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/).

Attribution: "Open Genes (open-genes.com), Open Longevity".

The software of Open Genes remains under its own licences (MPL-2.0 and others, as stated in each
repository). At the date above, the Open Genes site and API did not state a licence for the data;
this note fills that gap until such a statement is published there.
